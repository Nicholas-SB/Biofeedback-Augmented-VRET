# Biofeedback-Augmented Arachnophobia Simulator

Welcome to the GitHub page for the paper **Biofeedback-Augmented Virtual Reality as a Tool for Treating Arachnophobia**! This page displays the game files which can be compiled then played in Unity, or you can download the apk to directly play the game!

In order to run this game well, a smartphone-based Head-Mounted Display such as a ShineBox, a Magene H803 heart beat tracker, and a mid-level phone is required. Any other heart beat tracker won't work since the game is hard-coded to only recognize BLE signal from Magene H803, and the game will not work on conventional VR devices such as the Meta Quest.

## Steps To Use:
1. Download and install Biofeedback.apk in your phone
2. Use the Magene H803 by wrapping it on one arm and pressing the ON button
2. Open the Biofeedback application. The phone will automatically recognize Magene H803 when it is on and the screen should show options to pick the difficulty of the game
4. Pick the desired difficuly level
5. Put the phone inside a Head-Mounted Display immediately and use it on your head, making sure you are wearing it comfortably
6. You should now see the bedroom once the level has begun. Have fun!

## Technical Details 
This game is made using Unity with the C++ language. The equipment we used for testing the game are Shinecon 10.0 for the HMD, Magene H803 for the heart beat tracker, and ASUS ROG 6 to play the game.
