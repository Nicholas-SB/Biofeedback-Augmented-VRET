# Biofeedback-Augmented Arachnophobia Simulator

Welcome to the GitHub page for the paper **Biofeedback-Augmented Virtual Reality as a Tool for Treating Arachnophobia**! This page displays the game files which can be compiled then played in Unity, or you can download the apk to directly play the game!

In order to run this game, a Head-Mounted Display such as a ShineBox, a Magene H803 heart beat tracker, and a mid-level phone is required.
